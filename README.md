# Moodify — React Music Edition

Project React bertema mood dan musik dengan **audio lokal yang benar-benar dapat diputar**.

## Jalankan
```bash
npm install
npm run dev
```

## Audio bawaan
Folder `public/music/` berisi 6 audio instrumental demo original yang dibuat khusus untuk project ini:
- `happy.wav`
- `sad.wav`
- `chill.wav`
- `angry.wav`
- `romantic.wav`
- `energetic.wav`

Tidak membutuhkan Spotify, YouTube, API, atau koneksi internet untuk memutar audio tersebut.

## Cara mengganti lagu
Masukkan file audio milikmu ke `public/music/`, lalu ubah path `audio` pada `moodProfiles` di `src/App.jsx`.
